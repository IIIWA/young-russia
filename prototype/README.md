# Чёрно-белый прототип ПМК Петербурга

Прототип хранится в отдельной папке `prototype/`. Цветной сайт находится в корневых `assets/`, `dist/` и `build-site.mjs`.

## Как посмотреть и оставить комментарии

Из папки `prototype/` запустите:

```powershell
node server.js
```

Затем откройте `http://127.0.0.1:4175/`. Опубликованный прототип доступен по адресу [young-russia.ru/prototype/](https://young-russia.ru/prototype/). На каждой секции есть кнопка «Комментировать блок». Кнопка «Комментарии» внизу страницы открывает замечания к странице в целом и сводку по страницам. Локально замечания сохраняются в `comments.json` и остаются после перезагрузки.

Остановка сервера: `Ctrl+C`. Без локального сервера HTML-страницы открываются, но комментарии не сохраняются.

## Как редактировать

- Тексты и структура страниц: `build.py`.
- Данные клубов: `../data/clubs-vo.json`, `data/clubs-admiralteysky.json`, `../data/clubs-vyborgsky.json` и `../data/clubs-kalininsky.json`.
- Внешний вид: `assets/wire.css`. Позже можно заменить стиль, не меняя структуру страниц.
- Поиск и фильтры: `assets/app.js`.
- Комментарии: `assets/comments.js`, локальный `server.js`, серверный `api/comments.php`. На хостинге записи хранятся вне папки сайта и не входят в GitHub.

После правки исходников пересоберите HTML через Python:

```powershell
python .\build.py
```

Готовые файлы появляются в `site/`. Команда пересборки не трогает `comments.json`.

## Статус данных

Для Василеостровского, Адмиралтейского, Выборгского и Калининского районов добавлены страницы клубов на основе открытых источников. Для остальных районов созданы страницы-заготовки. Сведения о программах, расписании и контактах требуют проверки у организаторов.

# Чёрно-белый прототип ПМК Петербурга

Прототип хранится в `prototype/site/`. Для каждого основного типа страницы поддерживается один образец, который повторяет порядок смысловых блоков и заголовки локальной сборки в `dist/`. Серое оформление, подписи секций и комментарии помогают согласовывать структуру без привязки к цветному дизайну. Ранее согласованные страницы сохранены, но не синхронизируются по отдельности.

## Источники страниц

- `build.py` обновляет образцы главной, списка районов и страницы района на примере Василеостровского.
- `build-directions.mjs` обновляет образец страницы направлений и сохраняет пять старых адресов с переходом на неё.
- `sync-local.py` обновляет только образцы страницы клуба (`clubs/morskoy.html`) и занятия (`activities/morskoy-devyatyy-lad.html`).
- `check.py` сравнивает структуру шести образцов с локальной сборкой и проверяет ссылки на всех сохранённых страницах.

Снимок прежних страниц перед массовой синхронизацией хранится в `snapshots/2026-10-16-before-full-site-parity/site/`. Массовые копии маршрутов были удалены после уточнения области прототипирования.

В двух синхронизированных образцах используются локальные стили и скрипты под чёрно-белым слоем `site/assets/local-sync.css`. Аналитика из скрипта локальной сборки удалена. Для повторного запуска `sync-local.py` нужен Python 3 с пакетом `lxml`.

## Пересборка после правок локального сайта

Из корня проекта последовательно выполните:

```powershell
npm run build
python prototype/build.py
node prototype/build-directions.mjs
python prototype/sync-local.py
python prototype/check.py
npm run check
```

Генераторы обновляют только перечисленные образцы. Для новых типов страниц сначала согласовывайте структуру прототипа; для новых районов и клубов Петербурга действуют исключения из `AGENTS.md`.

## Просмотр и комментарии

HTML можно открыть напрямую из `prototype/site/`. Для работающей карты и сохранения комментариев запустите `node prototype/server.js` в постоянном терминале и проверьте страницу в браузере. Не считайте адрес `127.0.0.1` доступным, пока конкретная страница не открылась. Комментарии хранятся отдельно от генерируемых HTML.

Данные об условиях участия, расписании и наборе уточняйте у организаторов. Прототип не является официальным ресурсом учреждений.

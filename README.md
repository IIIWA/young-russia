# Young Russia — каталог ПМК Петербурга

**Начать работу над сайтом:** [единый статус и задачи сайта](YoungRussiaOBS/СТАТУС-САЙТА-И-ЗАДАЧИ.md). В нём собраны выполненное локально, текущие проверки и следующие этапы; правила для агента находятся в [AGENTS.md](AGENTS.md).

Публичный сайт: [young-russia.ru](https://young-russia.ru/). Прототип для обсуждения структуры: [young-russia.ru/prototype/](https://young-russia.ru/prototype/).

Сайт помогает находить бесплатные подростково-молодёжные клубы Санкт-Петербурга. В каталоге есть страницы районов и клубов, поиск и фильтры. Адреса, телефоны и направления Василеостровского района обновлены по списку ПМЦ от 12.10.2026. Действующий набор, возраст и условия участия в конкретной группе требуют уточнения у организаторов.

Кировский район добавлен по [текущему списку ПМЦ «Кировский»](https://pmckir.ru/?page_id=556): в нём перечислено 19 площадок, хотя на главной странице ПМЦ указано 20 подразделений. Направления сверены со страницами клубов и [городским PDF](https://www.spbdm.ru/upload/iblock/412/7s2lf23hff03g0ls4mgteb9m3nyjd26h/%D0%9F%D0%9C%D0%A6%20%D0%9A%D0%B8%D1%80%D0%BE%D0%B2%D1%81%D0%BA%D0%B8%D0%B9.pdf) от 01.06.2026. В источниках есть расхождения по составу, телефонам и адресам; они отмечены в `data/clubs-kirovsky.json` и на страницах площадок. Контакты собраны в `outputs/01a137a8-85c8-7221-8f87-bb9361ddfbf1/Контакты-ПМК-Кировский-район.xlsx`.

Фон страницы Кировского района создан встроенным генератором изображений: оптимизированная версия находится в `assets/hero-kirovsky.webp`, запрос и происхождение сохранены в `docs/district-hero-prompts.md`. Исходный PNG хранится локально в `source-assets/district-hero-generated/kirovsky.png` и не входит в репозиторий. На странице подписи нет.

## Сборка

```powershell
npm ci
npm run build
npm run check
```

Для сборки требуется Node.js 24.15+ или 22.22.3+. `.nvmrc` указывает проверенную версию 24.19.0. `npm run dev` запускает локальную разработку в Nuxt. `npm run build` генерирует статический сайт в `dist/` с прежними адресами `.html`; его можно размещать на существующем хостинге без Node.js. Для предпросмотра используйте `npm run preview` и открывайте адрес только после проверки, что сервер продолжает работать. Генерируемые страницы Nuxt содержат абсолютные ссылки на `/_nuxt/` и `/assets/`, поэтому открывать их через `file:///` нельзя.

Текущий переходный слой берёт каталог и HTML содержимое страниц из `build-site.mjs` и `data/`, преобразует их в отдельные данные страниц, после чего Nuxt выполняет рендеринг и предварительную генерацию маршрутов. Это сохраняет существующий контент, фильтры и адреса; для новых блоков можно писать компоненты Vue в `app/`. `npm run build:legacy` оставлен для сравнения с прежней сборкой. Новые районы Санкт-Петербурга и страницы их клубов на готовом шаблоне добавляются сразу в `dist/`, без нового прототипа. Для других городов сначала создаётся и согласовывается прототип, затем собирается продовая версия. Ранее согласованные страницы прототипа сохраняются в `prototype/site/`. Команда `npm run check` проверяет локальные ссылки и наличие прототипов для остальных типов страниц.

## Структура

- `app/`, `nuxt.config.ts` — приложение Nuxt и маршруты.
- `build-site.mjs`, `data/`, `assets/` — исходники существующего каталога и оформления.
- `scripts/prepare-nuxt-content.mjs` — подготовка данных страниц из каталога.
- `scripts/publish-nuxt.mjs` — перенос статической генерации Nuxt в `dist/`.
- `dist/` — готовые HTML, CSS, JavaScript и изображения.
- `prototype/build.py`, `prototype/data/`, `prototype/assets/` — исходники прототипа.
- `prototype/site/` — готовый прототип.
- `prototype/api/comments.php` — обработчик комментариев на хостинге; записи хранятся вне публичного каталога и не входят в репозиторий.

Прототип открыт по ссылке без пароля. Его страницы содержат `noindex`, чтобы поисковые системы не включали их в выдачу.

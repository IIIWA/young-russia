# Контакты и ссылки ПМЦ и ПМК Петербурга

Рабочий сбор от 16.10.2026 для последующего применения на Young Russia. Контакты из реестра не перенесены автоматически в опубликованные карточки клубов. Список адресов в `docs/address-checklist-2026-10-16.html` и `.md` использует его для показа найденных ссылок ВК рядом с направлениями из карточек.

Единый обзор клубов трёх районов: `YoungRussiaOBS/База данных/Каталог клубов Санкт-Петербурга.csv` (67 строк, 27 колонок, открывается в Excel) и Obsidian Base `YoungRussiaOBS/База данных/Каталог клубов Санкт-Петербурга.base` с 67 автоматически создаваемыми карточками. Обновление: `npm run data:views`. Данные каталога берутся из `data/clubs-vo.json`, `data/clubs-admiralteysky.json` и `data/clubs-vyborgsky.json`, контакты центров — из `pmc-centers-contacts.json` и пользовательских заметок. Исследовательские поля заполняются из `*-note-evidence.json` и внутренних заметок `YoungRussiaOBS/База данных/Специалисты Василеостровского района/`; исходные заметки сохраняют происхождение записей. Полная CSV хранится в исключённой из Git папке хранилища Obsidian, поскольку содержит ФИО и контакты специалистов. CSV и Obsidian Base нельзя редактировать как первоисточник: пересборка заменит их. Старые василеостровские заметки и отдельная адмиралтейская таблица сохранены как подробные рабочие материалы.

- `pmc-centers-contacts.json` — 18 центров: адреса, телефоны, почта, сайты, VK и известные дополнительные каналы. У каждого есть источник и примечание о проверке.
- `nevsky-official-club-links.json` — 32 VK-ссылки клубов, опубликованные на официальном сайте ПМЦ «Невский»; часть страниц содержит телефон.
- `kirovsky-official-club-pages.json` — 16 страниц клубов на официальном сайте ПМЦ «Кировский».
- `user-supplied-vk-links.json` — исходные девять ссылок на основные направления: пять у «Морского», четыре у «Витаны». Рабочая привязка к занятиям хранится в `data/clubs-vo.json` → `activityPages` и переносится в сводный реестр. Соответствия «Девятый лад» → «Гитара», «Аллегро» → «Соло-латина», INFINITY → «Чир-спорт» подтверждены пользователем. Связь «ЙОГАСОФИИ» с «Фитнес-йогой» пока предположительная. Четыре страницы направлений «Морского» есть в прототипе и локальной сборке; маршруты «Витаны» остаются рабочими данными.
- `vo-note-evidence.json` — данные для адресного листа из заметки по Василеостровскому району от 17.10.2026: 31 ссылка на ВК-страницы клубов и 13 связей сообществ с занятиями утверждены пользователем 18.10.2026; 347 строк расписания, 32 комментария к сверке и 909 строк дополнительных выдержек остаются материалами для проверки. Личные телефоны, ФИО специалистов и изображения сюда не перенесены. У «Надежды» и «Юности» прежние адреса сохранены как альтернативные адреса тех же страниц по подтверждению пользователя; страница «Центра туристской подготовки» общая с «Планетой». Адресный лист пересобирается из этого файла командой `node scripts/build-address-checklist.mjs`.
- `admiralteysky-note-evidence.json` — рабочий реестр Адмиралтейского района из заметки `YoungRussiaOBS/Задачи/Адмиралтейский район.md` и последующих уточнений: центр, 26 карточек каталога, 23 раздела клубов и связанных сообществ, телефоны, электронные адреса, ссылки, специалисты, фрагменты расписаний и номера строк источника. `admiralteysky-note-contacts.csv` — таблица для Excel (UTF-8 с BOM, разделитель `;`), включая отдельные колонки для ВК секций и их специалистов. Оба файла исключены из Git из-за персональных сведений. Пересобрать оба файла: `node scripts/build-admiralteysky-note-evidence.mjs`. [Разбор расхождений](../../docs/admiralteysky-note-review-2026-10-18.md). Шесть уточнений пользователя уже перенесены в локальный каталог; остальные записи остаются кандидатами для сверки. Персональные контакты из реестра не публиковать без отдельной проверки и решения.
- `vyborgsky-note-evidence.json` — внутренний разбор заметки `YoungRussiaOBS/Задачи/ПМК Выборгского инфа.md`: девять площадок каталога, 64 раздела направлений у шести из них, 101 фрагмент расписания, ссылки на клубы ПМЦ «МИР» и страницы направлений, строки источника, 33 упоминания специалистов в разделах. У «Ритма», «Лидера» и «Перспективы» в заметке найдены только ссылки клуба. Разделы без явно названной площадки сохранены отдельно и не приписаны клубам. Файл исключён из Git из-за персональных сведений; пересобрать командой `npm run data:views`. [Подробная база](../../YoungRussiaOBS/База%20данных/ПМК%20Выборгского%20района.base) содержит сведения для сверки, а не для автоматической публикации.
- Расписание и контакты «Морского» и «Витаны» сверены 16.10.2026 по официальным карточкам ПМЦ: `https://www.pmcvo.ru/pmkmorskoi.html` и `https://www.pmcvo.ru/pmkvitana.html`. В `data/clubs-vo.json` сохранены расписания всех перечисленных на карточках занятий. Отдельное уточнение пользователя от 18.10.2026: разговорный клуб немецкого языка работает также в субботу с 20:20 до 22:00; этого слота пока нет на странице ПМЦ, поэтому источник указан у записи и пояснён на локальной странице занятия. Для подтверждённых связей с VK-группами расписание также добавлено в `activityPages`. «ЙОГАСОФИИ» расписание «Фитнес-йоги» пока не приписано.
- В прототипе карточка ПМК «Морской» ведёт на четыре страницы направлений. Разговорные занятия пока объединены на одной странице с расписанием по трём языкам и двумя полученными VK-ссылками; остальные направления имеют отдельные страницы. Соответствия сохранены в `prototypeRoute` сводного реестра.
- Пользователь подтвердил, что сообщество «Как это сказать по-...?» относится к английскому и немецкому языкам; у японского языка отдельное VK-сообщество. На странице разговорного клуба оба сообщества расположены выше расписания.
- Четыре страницы направлений «Морского» теперь формируются одним шаблоном `prototype/build-morskoy-directions.mjs`: описание → VK-сообщества → расписание → адрес и контакты ПМК → порядок связи перед первым занятием. Предыдущие версии сохранены в `prototype/snapshots/2026-10-16-unified-directions/`.
- `pmc-club-contact-audit.json` — сводка 334 карточек из `data/clubs-*.json`, включая направления, ссылки ВК клубов и отдельных занятий, а также страницы Невского, Кировского и Адмиралтейского центров. Все 22 страницы адмиралтейских клубов перенесены в `data/clubs-admiralteysky.json` из присланной заметки `YoungRussiaOBS/Задачи/Адмиралтейский район официальные стр.md`. Старые названия «Ровесник» и «Славяне» сопоставлены с нынешними «КАМИНом» и «Потоком» по уже сохранённым в каталоге прежним названиям, адресам и ВК. Доступность страниц в сети не проверялась. Пересобрать: `node scripts/build-pmc-contact-audit.mjs`. Список адресов затем обновляется командой `node scripts/build-address-checklist.mjs`.

В сводке есть 89 основных VK-ссылок клубов (31 утверждена пользователем для Василеостровского района) и 24 привязки ссылок к занятиям, включая 13 утверждённых пользователем для Василеостровского района и две присланные для КЮМ «Адмиралтеец» 18.10.2026. Связь «ЙОГАСОФИИ» с «Фитнес-йогой» остаётся предположительной. Также собраны 102 страницы клубов, телефоны для 223 клубов и 28 адресов электронной почты. Из телефонов 26 сверены по официальным страницам Невского центра. Утверждение ссылки не подтверждает её текущую доступность или актуальность набора. VK напрямую не открывался: браузер заблокировал доступ к `vk.ru` по правилу безопасности. Данные из раскрытого раздела «Ещё» можно дополнять по присланным пользователем скриншотам или тексту.

Перед переносом в карточки сайта сверить номер и адрес каждого клуба с текущим официальным источником. У ПМЦ «Петроградский» в материалах проекта и на действующем сайте указаны разные телефоны; в реестре сохранены оба. Не публиковать ФИО руководителей из источников без отдельного решения.

# Контакты и ссылки ПМЦ и ПМК Петербурга

Рабочий сбор от 16.10.2026 для последующего применения на Young Russia. Файлы здесь не подключены к опубликованным страницам.

- `pmc-centers-contacts.json` — 18 центров: адреса, телефоны, почта, сайты, VK и известные дополнительные каналы. У каждого есть источник и примечание о проверке.
- `nevsky-official-club-links.json` — 32 VK-ссылки клубов, опубликованные на официальном сайте ПМЦ «Невский»; часть страниц содержит телефон.
- `kirovsky-official-club-pages.json` — 16 страниц клубов на официальном сайте ПМЦ «Кировский».
- `user-supplied-vk-links.json` — исходные девять ссылок на основные направления: пять у «Морского», четыре у «Витаны». Рабочая привязка к занятиям хранится в `data/clubs-vo.json` → `activityPages` и переносится в сводный реестр. Соответствия «Девятый лад» → «Гитара», «Аллегро» → «Соло-латина», INFINITY → «Чир-спорт» подтверждены пользователем. Связь «ЙОГАСОФИИ» с «Фитнес-йогой» пока предположительная. Отдельные маршруты страниц направлений ещё не согласованы.
- Расписание и контакты «Морского» и «Витаны» сверены 16.10.2026 по официальным карточкам ПМЦ: `https://www.pmcvo.ru/pmkmorskoi.html` и `https://www.pmcvo.ru/pmkvitana.html`. В `data/clubs-vo.json` сохранены расписания всех перечисленных на карточках занятий. Для подтверждённых связей с VK-группами расписание также добавлено в `activityPages`. «ЙОГАСОФИИ» расписание «Фитнес-йоги» пока не приписано.
- В прототипе карточка ПМК «Морской» ведёт на четыре страницы направлений. Разговорные занятия пока объединены на одной странице с расписанием по трём языкам и двумя полученными VK-ссылками; остальные направления имеют отдельные страницы. Соответствия сохранены в `prototypeRoute` сводного реестра.
- Пользователь подтвердил, что сообщество «Как это сказать по-...?» относится к английскому и немецкому языкам; у японского языка отдельное VK-сообщество. На странице разговорного клуба оба сообщества расположены выше расписания.
- Четыре страницы направлений «Морского» теперь формируются одним шаблоном `prototype/build-morskoy-directions.mjs`: описание → VK-сообщества → расписание → адрес и контакты ПМК → порядок связи перед первым занятием. Предыдущие версии сохранены в `prototype/snapshots/2026-10-16-unified-directions/`.
- `pmc-club-contact-audit.json` — сводка 334 карточек из `data/clubs-*.json` с добавлением подтверждённых страниц Невского и Кировского центров. Пересобрать: `node scripts/build-pmc-contact-audit.mjs`.

В сводке есть 66 основных VK-ссылок клубов, 80 страниц клубов, телефоны для 223 клубов и 27 адресов электронной почты. Из телефонов 26 сверены по официальным страницам Невского центра. Это наличие сведений, а не подтверждение актуальности каждой страницы или контакта. VK напрямую не открывался: браузер заблокировал доступ к `vk.ru` по правилу безопасности. Данные из раскрытого раздела «Ещё» можно дополнять по присланным пользователем скриншотам или тексту.

Перед переносом в карточки сайта сверить номер и адрес каждого клуба с текущим официальным источником. У ПМЦ «Петроградский» в материалах проекта и на действующем сайте указаны разные телефоны; в реестре сохранены оба. Не публиковать ФИО руководителей из источников без отдельного решения.

## Результат

Обновлены 109 существующих клубных записей семи районов. Добавлены 89 ссылок на сообщества клубов и 101 официальная страница. Общий шаблон теперь показывает собственную официальную страницу клуба рядом с VK и сайтом учреждения, включая ранее пропускавшиеся карточки. Добавлены 39 категорий занятий; существующий порядок и старые маршруты сохранены. Новых физических клубов нет.

Сетки Пушкинского относятся к 2026-2027 учебному году. Для отбора сопоставлены название и площадка с однозначным бесплатным предложением официального перечня; возраст отдельной группы не придуман. Три смешанные платные/бесплатные строки «Ростка»/«Славянки» и объединённая строка «Футбол, ОФП» не перенесены. Две строки с разными специалистами одного направления сохранены отдельными колонками; общее субботнее время двух групп каратэ не удвоено.

У четырёх графиков «Атланта» бесплатность 14-35 лет прямо указана в том же блоке. Их период неизвестен и явно обозначен перед таблицей. Два графика «Купчино» взяты из сохранённых официальных карточек с явной бесплатностью 14-35 лет; период также не указан, требуется медицинская справка. Это дополнительные официальные сведения из пакета S-81, а не новые часы из текста ВК.

Для девяти клубов Приморского перенесены **76 записей бесплатных студий**: названия, исходные возрастные условия и ограничения. Они сопоставлены с официальным снимком по названию и клубу; часы из старых/недельных/совместных документов не унаследованы.

## Сохранено внутри

[Ведомость в базе](../YoungRussiaOBS/База%20данных/ВК%20—%20отбор%20для%20локального%20сайта%202026-10-28.md) и [точный JSON решений](../data/research/vk-public-import-2026-10-28/selection.json). Все 338 кандидатов получили решение. Из 338 исходных записей графиков S-81 42 вошли в 39 публичных расписаний, 296 оставлены внутри; ещё два расписания взяты из официальных карточек «Купчино». Число записей включает повторные версии, архив и нераспределённые изображения; это не число уникальных секций.

В базе остаются PDF «Радуги» 2025-2026, версии «Вымпела» и «Витуса», платные предложения, смешанные условия без распределения времени, часы сотрудников, все 34 нераспределённые строки изображений, неполная бесплатность, неоднозначные VK-алиасы/площадки и публикации Центрального 2021 года. Адрес «Кругозора» с домом 42 сохранён как исправление для совместной сверки связанной точки карты. Координаты и старый текст публичного адреса в этой партии не менялись.

Свежий импорт Петродворцового S-79-B-R2 сохранён побайтно. Его ранее принятые бесплатные спорные варианты с пояснениями этой партией не переоценивались и не заменялись старой заметкой ВК.

Пользовательская копия ВК не названа свежим посещением сообщества. Подтверждение всеми официальными представителями остаётся после наполнения сайта; обращения не отправлялись. Неизвестная бесплатность не объявлена платностью.

## Проверки

- [Независимая проверка PASS](../outputs/S-82/verification.json): все 307 интервалов совпали с исходными днями/временем/помещениями; все 76 студий и 101 официальная ссылка выведены. В новых графиках нет платных, архивных и конфликтных строк.
- 2395 защищённых файлов не менялись: в том числе 2271 прежний файл прототипов, принятые исследования и координаты. Все восемь оригинальных заметок и 24 записи происхождения вложений совпали по SHA256. 708 прежних маршрутов направлений восьми каталогов доступны.
- `data:views` PASS: общая внутренняя Base остаётся 329 записей / 18 районов, вопросы и исходные графики сохранены.
- Сборка выполнена совместимым Node 24.22.1 по командам скрипта build: подготовка контента, Nuxt generate, publish-nuxt. Начальная попытка остановилась на защите связанного адреса карты; изменение адреса отложено, окончательная сборка PASS. npm из Node REPL не запускал составную команду корректно, поэтому сборочный pipeline выполнен непосредственно; `npm run data:views` и `npm run check` затем успешно выполнены в PowerShell.
- `npm run check` PASS: **2496 HTML / 2494 canonical**, локальные ссылки, необходимые прототипы, метаданные, sitemap и noindex. Известные предупреждения Nuxt о payload/chunk size не являются новыми ошибками данных.
- [Браузер, 375 px](../outputs/S-82/browser-mobile-final.json): все 41 расписание / 307 слотов, горизонтального переполнения нет, не более двух колонок групп. [Пять сложных широких вариантов](../outputs/S-82/browser-desktop.json) PASS; переход из клуба, возраст киностудии и [собственные ссылки клуба](../outputs/S-82/browser-club-links.json) проверены.

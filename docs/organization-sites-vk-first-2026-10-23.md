# Официальные сайты учреждений и первая кнопка VK

Дата: 23.10.2026. Задача S-63. Изменения есть в исходниках, локальных базах и на young-russia.ru. Отдельный коммит и push не выполнялись.

## Причина пропуска

Генератор адресного списка содержал отдельный список учреждений. У «МИРа» и «Форпоста» там отсутствовали сайты, хотя сведения о клубах уже были добавлены. Основной шаблон карточек также выводил официальный сайт раньше VK, а 32 известных сообщества Невского района оставались только в исследовательском реестре.

## Исправление

- [Официальный сайт «Форпоста»](https://xn----gtbyjafgkjo.xn--p1ai/) и [официальный сайт ПМЦ «МИР»](https://xn----ptbkbv6a.xn--p1ai/) добавлены в общий справочник учреждений, [адресный список](address-checklist-2026-10-16.html) и подробные карточки Выборгского района. HTTP-адрес «Форпоста», присланный пользователем, перенаправляет на HTTPS; сохранён конечный адрес.
- Генераторы адресного списка и выборгской базы берут сайты из общего справочника. В карточках клубов сохраняются их собственные официальные страницы; ссылка учреждения их не подменяет.
- Во всех **334 карточках** первая контактная кнопка ведёт в VK. Для **98 карточек** используется основная ссылка из каталога: 95 отдельных и три общих сообщества. Для **236 карточек** без записанного собственного сообщества показана кнопка «ВКонтакте учреждения».
- Общая группа явно подписана: «Феникс» и «Фестиваль» используют группу «Форпоста», Центр туристской подготовки Василеостровского района — группу «Планеты».
- 32 ссылки Невского района перенесены из ранее собранных официальных страниц в основной каталог. Их прежняя дата источника 16.10.2026 сохранена; импорт датирован 23.10.2026.
- Добавлены отсутствовавшие сведения об учреждениях: «Форпост», «Колпинец», Кронштадтский дворец, «Царскосельский», Дом молодёжи Приморского района и «Пулковец». VK «Колпинца», Кронштадтского дворца, «Царскосельского» и Дома молодёжи Приморского района взяты с официальных сайтов; для «Форпоста» использована уже известная группа. Для «Пулковца» переиспользована существующая ссылка проекта без заявления о новой сетевой проверке.
- Адреса электронной почты располагаются после кнопок. Порядок общих контактов на страницах занятий приведён к тому же правилу; отдельные сообщества направлений сохранены.

## Проверки

- Пересобраны внутренние представления: 67 общих карточек, 26 подробных Адмиралтейского района и девять Выборгского; сводный реестр и HTML/Markdown списка адресов.
- Сборка и npm run check прошли: 1891 HTML, 1889 canonical URL, 1888 BreadcrumbList, локальные ссылки и sitemap без ошибок.
- Проверены все 334 карточки: правильная первая VK-ссылка, оформление основной кнопки, сохранность официальной страницы клуба, верная подпись сообщества.
- Chrome: девять клубов на ширинах 390 и 1440 px до и после публикации, всего 36 проверок отображения. VK остаётся первой после запуска Vue, кнопки помещаются на экране. Дополнительно проверена страница объединения «Мы вместе» у «Патриота».
- Локальный адресный список открыт в Chrome; обе официальные ссылки учреждений Выборгского района присутствуют.
- После публикации все 334 карточки и ещё шесть адресов ответили HTTP 200 и совпали со сборкой по SHA-256. Sitemap содержит 1889 URL, robots доступен, публичный ключ IndexNow сохранился. Метрика 113739844 присутствует в проверенных HTML.
- Сами страницы VK и актуальность набора не проверялись. Наличие сообщества учреждения не доказывает существование отдельной группы каждого клуба.

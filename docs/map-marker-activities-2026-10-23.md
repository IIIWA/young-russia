# Направления клуба во всплывающей карточке карты

Дата: 23.10.2026. Статус: опубликовано 23.10.2026, 20:44:28 МСК по следующему запросу пользователя «добавляй все на прод». [Отчёт выпуска](kolpinets-all-release-2026-10-23.md).

На интерактивных Яндекс Картах главной, 18 районных каталогов и общего каталога направлений карточка метки показывает полный список занятий клуба. Источник — `activities` основного каталога. При выборе занятия в общем каталоге сохраняется строка о соответствии фильтру, ниже доступны остальные направления клуба.

Для языковых клубов отдельно перечисляются языки, явно названные в данных. Для общего названия вроде «Билингва» показано «список уточняется у клуба». Неназванные языки не добавляются. Длинные списки сохраняются целиком с прокруткой внутри списка. Ссылки на клубы имеют явные синие цвет и подчёркивание в разметке метки.

## Проверки

- `npm run build` и `npm run check`: 2006 HTML, 2004 canonical, 2003 BreadcrumbList, локальные ссылки и обязательные прототипы прошли проверку.
- Все 331 клуба с точкой на главной и все 18 районных наборов сверены с `activities` исходного каталога. После параллельного обновления адресов Колпинского района сверка данных карты повторена на изолированной сборке `.deploy/marker-current-catalog/` из текущих исходников, без замены общей Nuxt-сборки другой задачи. Правка меток не меняет координаты. [Машинный отчёт](map-marker-activities-2026-10-23.json).
- В браузере проверены «Морской» на районной карте и карте направлений: четыре направления, английский, немецкий и японский.
- «Аврора»: четыре занятия и пояснение о неуточнённых языках.
- «Атлант»: все 44 направления присутствуют; высота списка 180 px, содержимого 945 px, доступна внутренняя прокрутка.
- На ширине 390 px карточка «Морского» помещается в экран. Ссылка имеет вычисленный цвет `rgb(29, 78, 216)` и подчёркивание.

SHA256 ответа HTML и сохранённого UTF-8 снимка разделены: `sha256` относится к ответу сервера, `snapshotSha256` — к локальному HTML с возможной сменой кодировки/переводов строк. Для скачанных вложений проверены реальные байты файлов.

## Проверка и границы

[Проверка JSON и файлов](../../outputs/S-79/collector-b/validation.json) прошла: необходимые поля, покрытие 48 карточек, адреса каждой исследовательской записи, дни недели, корректность интервалов, SHA256 460 локальных файлов. Два повторяющихся исходных интервала явно перечислены; это вопросы к источнику, а не два дополнительных уникальных занятия. В пакет вошли 111 ответов/снимков страниц с учётом зеркал и повторных проб, 75 записей попыток получения документов, из них 71 успешный ответ. Все текущие файлы расписаний получены.

Растровые изображения просмотрены для классификации на контактных листах, кандидаты с часами — в полном размере. Сохранены 158 уникальных изображений из паспортов доступности. Все PDF-расписания и прейскуранты просмотрены; текстовые административные документы и нерелевантные сканы имеют отдельные честные статусы разбора. Скачивание и OCR не обозначены как визуальное чтение.

Прямая проверка работоспособности VK не проводилась: ссылки подтверждаются только размещением на официальных сайтах. Исключение процесса: общий загрузчик ошибочно принял один `style` URL VK «Навигатора» за изображение и получил HTML. Ответ не использован для верификации, исключение сохранено в `scopeExceptions` Петродворцового JSON; повторные запросы VK заблокированы в сборщике. Обычный значок-эмодзи с CDN VK является изображением, а не проверкой сообщества. Случайно захваченные 26 фоновых видео не анализировались; их 1.246 ГБ локальных байтов удалены, URL, размер и SHA256 оставлены в журнале исключений.

Запись ограничена тремя выделенными папками источников, `collector-b`, тремя новыми исследовательскими JSON и этим отчётом. Общий `collect_sources.py`, существующие каталоги, Base, генераторы, `dist/`, прототипы, реестры, Git index/история и сервер не менялись. Сборка, коммит, push и SSH не запускались. Итог передаётся на приёмку; перенос в каталог и публикация не выполнены и не входят в это задание.

# Первый технический SEO-пакет, 22.10.2026

Статус: опубликован на https://young-russia.ru/ 22.10.2026 по подтверждению пользователя. Проверки HTTP и браузера прошли, Search Console обработала актуальную карту.

## Изменения

- `scripts/page-seo.mjs` формирует абсолютные canonical без query/hash, различимые title/description с районом и городом и BreadcrumbList из существующей видимой навигации. Главная канонизируется к `/`, остальные действующие `.html` адреса сохраняются.
- `scripts/prepare-nuxt-content.mjs` сохраняет SEO-поля в данных Nuxt; `app/components/CatalogPage.vue` выводит их в предварительно сгенерированный HTML. Главная получила поисковый title «Бесплатные кружки и секции в Санкт-Петербурге | ПМК Петербурга». Видимый H1 и структура страниц не менялись.
- `public/.htaccess` подготовлен для Apache/ISPmanager: www → основной домен, `/index.html` → `/` с сохранением параметров и локальная страница ошибки 404. Проверка THE_REQUEST предотвращает цикл с DirectoryIndex. HTTPS остаётся под управлением существующей настройки хостинга.
- `scripts/publish-nuxt.mjs` переносит `.htaccess` в сборку и добавляет `noindex,nofollow` в технические `200.html` и `404.html`.
- `scripts/check-seo.mjs` включён в `npm run check`: canonical, уникальность метаданных, корректность JSON-LD и последовательности хлебных крошек, совпадение sitemap с маршрутами, noindex технических файлов.

# Читаемость расписаний и почтовые контакты

Дата: 23.10.2026. Статус: опубликовано 23.10.2026, 20:44:28 МСК вместе с уточнением отступов, картами и «Колпинцем». [Отчёт выпуска](kolpinets-all-release-2026-10-23.md).

## Что изменено

- Общий генератор расписаний выводит таблицы максимум по две группы на телефоне, планшете и десктопе. Дни расположены в строках; прежняя отдельная тесная десктопная таблица удалена.
- В цветной ячейке время и помещение расположены отдельными строками. Кабинет выровнен по нижнему краю с внутренним отступом. Увеличены высота ячейки и промежутки; короткие подписи не разбиваются по буквам.
- Почта выводится самим адресом, обычным текстом после кнопок. Общий обработчик удаляет mailto-ссылки также из старых клубных шаблонов, сохраняя адрес. Новые прототипы получают тот же формат; ранее сохранённые прототипы не перезаписывались.
- Правила закреплены в AGENTS.md. Утверждённые специальные расписания «Морского» и бокса «Адмиралтейца» сохранены.

Исходники: `build-site.mjs`, `scripts/activity-schedule-markup.mjs`, `assets/style.css`.

## Проверки

- `npm run build`: 2004 маршрута Nuxt, 2006 HTML с техническими страницами. Завершение подтверждено сообщением `Published 2004 Nuxt pages` в `.deploy/schedule-layout-build-20261023.log`.
- `npm run check`: локальные ссылки, сохранённые прототипы, 2004 canonical, 2003 BreadcrumbList, sitemap и noindex проверены.
- Сверка всех 212 записей расписаний: 1405 сочетаний дня, группы, времени и помещения сохранены; 1340 значений помещения. Получено 394 таблицы, каждая максимум с двумя группами. Сверка выполнялась по полному набору значений из источника, а не только по числу ячеек.
- В 2006 HTML нет действующих ссылок `mailto:` и надписи «Написать организатору». Адреса текстом есть на 1774 страницах; новый общий формат расписания используется на 207 страницах. Эти количества отличаются от исходных 212 записей, поскольку утверждённые специальные страницы используют собственную разметку.
- В локальном браузере проверены «Современный танец» при 320/768/1280 px и «Эстрадный танец» при 320/768/1163 px. Во всех шести случаях максимум две группы в таблице, кабинет ниже времени, у нижнего края слота, переполнения страницы нет. Почта после гидратации остаётся текстом.

## Уточнение отступов 23.10.2026

По следующему замечанию пользователя уменьшена минимальная высота общих цветных ячеек: 80 → 72 px на планшете и десктопе, 68 → 60 px на телефоне. Минимальный промежуток между временем и кабинетом установлен в 6 px. Высота остаётся минимальной: при длинной подписи ячейка свободно растёт. Шрифты сохранены, кабинет остаётся снизу.

Правило применяется ко всем страницам с общим расписанием. Обновлён также шаблон для будущих прототипов; сохранённые снимки не перезаписывались. В специальных таблицах языков, гитары, кинологии, фотографии и бокса такой многострочной подписи с большим промежутком нет.

Повторные `npm run build` и `npm run check` прошли: 2006 HTML / 2004 canonical. В браузере при 1011/768 px промежуток уменьшился с 14,85 до 6,85 px, при 320 px с 15 до 7 px. Переполнения страницы и ячеек нет; шрифты не уменьшались. [Измерения до и после](../outputs/schedule-spacing-browser-2026-10-23.json), [снимок обновлённых отступов](../outputs/schedule-spacing-desktop-2026-10-23.png). Уточнение опубликовано в составе общего выпуска 23.10.2026.

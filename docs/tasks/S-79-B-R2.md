# S-79-B-R2: перенос Петродворцового района в БД и локальную сборку

Запуск 28.10.2026, чат `01a15533-c716-7b20-a180-0b2ae9870591`, local. Прямая команда пользователя: «Добавь собранные данные Петродворцового района в БД и на локалку, а спорные расписания на локалку добавляй только бесплатные, информацио о платных сохрани где-то».

## Область записи

Данные десяти клубов Петродворцового района, их общий/подробный внутренний обзор, адаптация генератора внутренних представлений для датированного приложения S-79-B-R1, сведения организации, примечание источника района в генераторе сайта, датированный импорт/отбор и архив платных/неопределённых сведений. Пересборка локального сайта и требуемых новых прототипов направлений по существующему шаблону; прежние сохранённые прототипы не переписывать. Очередь, центральный статус и доказательства проверки.

Принятый пакет S-79 от 26.10.2026 и исходный снимок S-79-B-R1 сохраняются. Во внутренней БД остаются все исходные строки с периодами, источниками и вопросами; платность и отсутствие её подтверждения — разные состояния. Для локальных расписаний требуется основание бесплатности: конкретное направление в бесплатной колонке городского документа либо явное бесплатное предложение клуба «М-51» для молодёжи 14–35 лет. Сложные/неотождествлённые новые строки без такого основания остаются внутри. Спорные бесплатные варианты можно показать с ясным описанием расхождения, без выдуманного выбора часов/групп.

## Проверка

Сверить три страницы городского PDF с разделением бесплатных/платных предложений. Проверить, что названия направлений, часы, дни, выездные места и общий интервал нескольких направлений не потеряны. Проверить родные VK десяти клубов, сохранность остальных районов, отсутствие платного предложения «Искорки» в публичных данных. Выполнить `npm run data:views`, `npm run build`, `npm run check`, адресные проверки итоговых HTML и просмотр расписаний на широком/узком экране. Это локальная задача, без SSH, публикации и Git-этапа.

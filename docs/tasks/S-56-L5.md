# S-56-L5: флаги языков над точками карты

Запущено прямым браузерным комментарием пользователя 29.10.2026, чат `01a13a3e-5dc5-7c02-a74f-7312fd5c7e65`, local.

Над точками карты языкового прототипа показать флаги всех языков клуба по существующему `point.languages`. Для жестового языка SL, для неизвестного языка вопросительный знак; страны не приписывать предположением. Сохранить цвет обычных/предварительных точек, координаты, карточки с языками и синими подчёркнутыми ссылками, районный фильтр. Открытие карточек работает по нажатию и с клавиатуры. Бокс использует прежние стандартные метки.

Область записи: `prototype/site/assets/topic-map.js`, `prototype/site/assets/guide-pages.css`, управляющие документы; HTML/JSON, каталог и Nuxt не пересобираются. Резервная копия: `backups/language-map-flags-2026-10-29/`; свидетельства: `outputs/language-map-flags-2026-10-29/`. Проверить карту на телефоне/десктопе, одно- и многоязычные клубы, нейтральные метки, popup и фильтр/сброс, отсутствие регрессии бокса; `npm run check`. Используется поддерживаемый `iconLayout`/`iconShape` API Яндекс Карт 2.1: https://yandex.com/dev/jsapi-v2-1/doc/en/v2-1/ref/reference/Placemark .

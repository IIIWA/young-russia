# S-56-L1: английский на всю ширину таблицы

Запуск: прямой браузерный комментарий пользователя 29.10.2026 в чате `01a13a3e-5dc5-7c02-a74f-7312fd5c7e65`: плашку английского расположить над клубами, клубы английского языка растянуть на всю ширину. Работа последовательная, после локального переноса бокса S-56-B2.

## Объём

- В просмотренном разговорном прототипе плашка «Английский, 22 клуба» располагается отдельной строкой над ссылками. Ссылки занимают обе колонки таблицы.
- Другие языки сохраняют две колонки; флаг, все ссылки, данные карты и состав подборки сохраняются.
- Меняется общий исходный рендер таблицы в `scripts/build-topic-page-prototypes.mjs`, CSS `prototype/site/assets/guide-pages.css` и текущий `prototype/site/guides/razgovornye-kluby.html`.
- Для применения изменения к просмотренному снимку используется тот же чистый преобразователь разметки; полный импорт обновлённого каталога и смена состава подборки не выполняются.
- Предыдущий снимок: `backups/language-guide-2026-10-29-before-wide-english/`. Свидетельства: `outputs/language-guide-wide-english-2026-10-29/`.

## Приёмка

Английский имеет заголовок и список с `colspan="2"`; все прежние ссылки и 22 клуба сохранены. Подпись таблицы связана с ячейкой списка через `headers`. В браузере проверены 1280, ширина комментария 693 и 320 px без горизонтальной прокрутки. `npm run check` проходит. Прототип бокса и его Nuxt-сборка этой задачей не меняются. Перенос разговорного гида в Nuxt, Git и публикация не входят в поручение.

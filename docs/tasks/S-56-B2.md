# S-56-B2: бокс в локальной Nuxt-версии

Прямая команда пользователя от 29.10.2026: «давай сделаем для локалки бокс». Чат `01a13a3e-5dc5-7c02-a74f-7312fd5c7e65`, local, существующая папка, один последовательный писатель. Текущая структура и короткие формулировки S-56-B1 служат согласованным вариантом для этого переноса.

## Результат и границы

- Собрать `/guides/boks.html` и необходимый вход `/guides/index.html` через текущий Nuxt-процесс.
- Сохранить 16 клубов, карту Яндекса, фильтр, таблицу адресов, ссылки на реальные страницы занятий и меню пяти направлений.
- Добавить путь к гиду в общую навигацию. Производственный вариант использует шапку и подвал сайта, без комментариев и обозначений прототипа.
- Сохранить просмотренные прототипы как снимки; разговорный гид не переносить и не пересобирать.
- Проверить canonical, метаданные, хлебные крошки, sitemap, наличие содержимого в статическом HTML и работу после гидратации.

## Файлы

`scripts/build-topic-page-prototypes.mjs` (общий исходный шаблон и отдельный экспорт для локальных гидов), `build-site.mjs`, `scripts/prepare-nuxt-content.mjs`, `app/components/CatalogPage.vue`, новые `assets/guide-pages.css` и `assets/guide-page.js`; производные `.data/`, `app/content/`, `public/`, `.output/` и `dist/`. Управляющие записи в `TASKS.md` и едином реестре. Снимки исходников в `backups/boxing-guide-nuxt-2026-10-29/`, свидетельства в `outputs/boxing-guide-nuxt-2026-10-29/`.

## Приёмка

1. `npm run build` и `npm run check` проходят; обе новые страницы имеют сохранённые прототипы и корректные ссылки.
2. Все 16 клубов и адресов совпадают с прототипом; состав групп, возраст и наличие мест остаются на уточнении.
3. В браузере проверены десктоп и телефон, меню, переход к занятию, фильтр/сброс и карта; нет горизонтальной прокрутки.
4. Постоянный локальный просмотр подтверждён HTTP и браузером; скриншоты сохранены.
5. Результат и следующий шаг записаны в едином реестре. Сервер, Git-коммит, GitHub push и перенос других гидов этой командой не разрешены.

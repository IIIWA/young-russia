Для production: свежая проверка цели после подтверждения SSH, полный бэкап с хешем, сохранение служебных файлов/комментариев/старых открытых ресурсов, проверка staging, атомарное переключение и внешние HTTP/браузерные проверки либо честно названная невыполненная часть. Git и live-site фиксируются отдельно в едином реестре.

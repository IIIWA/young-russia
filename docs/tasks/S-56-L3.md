## Объём и приёмка

- На экранах до 1100 px и устройствах с основным сенсорным указателем таблица показывает только выбранный язык. На широком десктопе видны все языки.
- По умолчанию выбран английский; язык из существующего якоря URL имеет приоритет. Активная кнопка различима, смена языка сохраняет доступ к кнопкам и поддерживает клавиатуру и историю браузера.
- При смене ширины выбранный язык сохраняется; без JavaScript остаются полная таблица и обычные якоря.
- Все 32 клуба, 22 английских клуба, ссылки и карта сохраняются. Полный импорт каталога не выполняется.
- Проверить телефон, планшет, десктоп, возврат назад и прямую ссылку на корейский. `npm run check` проходит.

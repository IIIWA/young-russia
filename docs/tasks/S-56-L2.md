## Объём

- Кнопки оформляются как ссылки для перехода к соответствующему языку. Они содержат флаг и название; для жестового и неуказанного языка используются нейтральные обозначения.
- Удаляется только видимая шапка языковой таблицы; сохраняются её доступная подпись, ширины колонок и английский блок на всю ширину.
- Сохраняются все исходные клубы, ссылки и JSON карты просмотренного снимка. Полный импорт каталога не выполняется.
- Запись: `scripts/build-topic-page-prototypes.mjs`, `prototype/site/assets/guide-pages.css`, `prototype/site/guides/razgovornye-kluby.html`, управляющие документы и `outputs/language-guide-flag-buttons-2026-10-29/`.
- Предыдущий вариант: `backups/language-guide-2026-10-29-before-flag-buttons/`.

## Приёмка

Для каждой строки языка есть подписанная кнопка-переход с рабочим якорем. Семь иностранных языков имеют свои SVG-флаги; жестовому и неизвестному языку национальный флаг не приписывается. Навигация работает с клавиатуры без нового JavaScript. На десктопе и телефоне нет горизонтальной прокрутки; английский список и остальные две колонки сохранены. `npm run check` проходит. Nuxt-бокс, публикация и Git не входят в поручение.

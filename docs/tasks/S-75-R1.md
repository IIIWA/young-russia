## Работа

1. Найти осенний источник «Молодости» или точно установить, для каких из 16 архивных расписаний обновление пока отсутствует.
2. Сверить открытые вопросы времени фитнеса и АРТ-студии, этажа тенниса и состава специалистов. Сначала использовать точные вопросы и ссылки из отчёта, затем новые официальные свидетельства.
3. Для найденных данных сохранить площадку, группу, условия, период, URL и точную строку. Сопоставить с существующими записями без стирания архивного графика. Не путать часы специалиста, свободное посещение и занятие.
4. Подготовить перечень точных правок и вопросов организаторам. Связь с людьми и учреждениями в эту исследовательскую задачу не входит.

Запись только в `docs/reviews/S-75-R1.md`, `docs/reviews/S-75-R1.json` и `outputs/S-75-R1/`. Перенос в публичный каталог и Base, сборка и публикация запускаются отдельно.

- У каждого архивного графика есть результат сопоставления с осенью, ссылка или явный пробел.

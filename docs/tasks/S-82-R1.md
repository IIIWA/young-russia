# S-82-R1: проверка ссылок VK

Запуск 28.10.2026, текущий управляющий чат `01a145eb-4fc1-7a92-a9f8-1b64f87ef1b3`, local, существующая папка. Прямая команда: «вк клуба Антей пишет что такой страницы нет, можешь проверить остальные ссылки на вк?». Во время работы пользователь нашёл актуальный адрес `https://vk.ru/bjj_antey` и прислал сведения/снимок расписания.

## Область и критерии

Все VK-ссылки текущей сборки; привязка к клубам/направлениям, синтаксис, ссылки источников, свежая сверка доступных официальных HTML. Пользовательское уточнение «Антея» вносится в каталог и базу; старые адреса и происхождение сохраняются. Фитнес/шахматы и часы открытия не становятся бесплатным расписанием без соответствующего основания. После исправления: локальная сборка, check и браузерная проверка. Commit/push/SSH/публикация не входят.

## Ограничение прямой проверки

Browser Use отклонил чтение уже открытой страницы https://vk.ru/anteybjj по site-safety policy; альтернативный браузер, прямые HTTP к VK, CDP, мобильный домен или поиск копий заблокированной страницы не используются как обход. Доступность сообществ остаётся неизвестной, кроме явно сообщённых пользователем состояний. Разрешённая часть: собственные файлы и официальные сайты учреждений, без переходов на VK. Совпадение с официальным источником не называется доступностью сообщества.

# Правки статей по комментариям браузера

Дата: 22.10.2026. Статус: готово локально, ожидается повторный просмотр пользователем. Структура статей ещё не утверждена для переноса в производственный Nuxt-шаблон.

## Выполнено

1. Убрано выделенное «есть» из вводного текста разговорной статьи. Начало теперь оформлено через двоеточие: «Бесплатные разговорные клубы в Санкт-Петербурге: 12 площадок из каталога Young Russia».
2. Основной текст обеих статей, вводный абзац, обычные списки и вопросы FAQ уменьшены до 16 px на широкой и узкой экранах. Размеры заголовков и небольших служебных подписей сохранены.
3. В данных точек разговорной карты появился список языков из названий направлений исходного каталога. При построении подписи он выводится отдельной строкой «Языки». У «Морского» это английский, немецкий и японский. У «Экватора» конкретные языки не указаны, поэтому выводится «Языки: уточнить у клуба». Для бокса строка языков не добавляется.
4. Все ссылки в восьми используемых шаблонах подписей карт оформлены синим `#1d4ed8` и подчёркиванием. Оформление задано непосредственно на ссылках, чтобы стили провайдера карты не превращали их в обычный текст. Оно сохраняется после посещения ссылки.
5. Общее правило для всех страниц, включая прототипы, записано в `AGENTS.md`: ссылки в подписях точек визуально отличаются от текста; в языковых подборках показываются языки клуба по данным каталога.

Текст и данные изменены в источниках: `data/editorial-guide-drafts.json` и `scripts/build-topic-page-prototypes.mjs`. Подписи формируют `assets/site.js`, `prototype/assets/map-preview.js` и четыре скрипта карт в `prototype/site/assets/`. При будущей синхронизации `local-site.js` правило наследуется из `assets/site.js`.

Просмотренные HTML, изменяемые исходники и прежние общие скрипты сохранены в `backups/seo-guides-2026-10-22-before-browser-comments/`. Предыдущие снимки и отклонённые варианты страниц не удалялись.

## Проверки

- `npm run prototype:topics`: пересобраны две статьи и вход в раздел; в картах 12 разговорных клубов и 13 клубов бокса.
- В изолированном JavaScript-тесте выполнен настоящий `topic-map.js` с данными из новых HTML и подставленной моделью API карты. Проверены 25 подписей, языки «Морского», неизвестный список «Экватора», отсутствие языковой строки у бокса и оформление всех ссылок. Это проверка построения подписей, не проверка реальных кликов по Яндекс Карте.
- Проверены все восемь шаблонов ссылок подписей, синтаксис изменённых JavaScript-файлов и разрешение локальных ссылок трёх страниц гида.
- Nuxt с Node 24.19.0 сгенерировал 1890 маршрутов. На завершающем копировании Windows возвращала `UNKNOWN` для существующих файлов. В `scripts/publish-nuxt.mjs` добавлены ограниченные повторы этого кода ошибки и запись noindex для служебных HTML через временный файл и копирование. После исправления отдельный запуск этого этапа успешно обновил 1888 локальных страниц в `dist/`.
- `npm run check` прошла: 1890 HTML, 1888 canonical, уникальные title/description, 1887 BreadcrumbList, корректные sitemap и noindex служебных файлов.
- `dist/assets/site.js` совпадает с обновлённым исходным скриптом; в каждом из двух служебных HTML ровно одна добавленная метка noindex.

Браузер отклонил чтение открытой пользователем страницы `file://` из-за ограничения разрешённых протоколов. Повторной визуальной проверки шрифта и реального клика по карте нет. При открытии прототипа с диска остаётся предусмотренная заглушка карты: сам интерактив требует HTTP-просмотра или публикации на сайте.

Основной текст остаётся 16 px. Предыдущий просмотренный вариант сохранён в `backups/seo-guides-2026-10-22-before-desktop-widening/`.

## Интерфейс и карты

- В списке районов Выборгский получил обычную карточку `ready`, без жёлтого выделения, специальной подсказки и подписи «данные уточняются». Число девять сохранено; внутренние вопросы по данным не удалены.
- Районный поиск учитывает видимый префикс «ПМК», все слова запроса, кавычки, регистр и ё/е. «ПМК «Олимп»» находит клуб. Запрос сохраняется в `q`.
- Выбор темы/подгруппы/учреждения записывает отдельное состояние истории; Back/Forward восстанавливают фильтры и запрос. Независимая проверка исходников — [SOURCE-GO](reviews/S-98-UX-2026-10-31.md); реальный браузер также подтвердил переход knowledge → sport → Back/Forward.
- Общий Clusterer больше не получает все метки. На районной карте и карте каталога он может получить только «Камчатку» и «Отвагу» по их точным маршрутам. Третий клуб в эту группу не попадает; один участник показывается отдельно. Главная остаётся без кластеризации. Прежние составные подсказки для **точно совпадающих** координат сохранены: это отдельное поведение, а не группировка близких точек по масштабу.

В реальном Яндекс API на телефоне проверены группа «2» для разрешённой пары, разделение при приближении до 21, открытие «Камчатки» и синие подчёркнутые ссылки, одиночная «Отвага», отсутствие кластеров у Калининского и на главной. [Свидетельства карт](../outputs/S-98/map-browser.json).

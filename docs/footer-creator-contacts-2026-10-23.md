# Контакты создателя в футере

Дата: 23.10.2026. Статус: опубликовано на young-russia.ru 23.10.2026, проверено в браузере.

## Изменение

В общий шаблон футера добавлена отдельная строка «Сайт разработан» с двумя ссылками. Формулировка уточнена пользователем после просмотра, тире убрано:

- ВКонтакте: https://vk.ru/iiiwaa
- Telegram: https://t.me/IIIWA6

Текст: «По вопросам и предложениям пишите в личные сообщения». Короткие предлоги и союзы связаны неразрывными пробелами. Ссылки подчёркнуты, открываются в новой вкладке с noopener noreferrer.

Исходники: build-site.mjs, assets/style.css. В AGENTS.md зафиксировано исключение для явно запрошенных пользователем контактов создателя. Ранее сохранённые прототипы остаются снимками и этой задачей не пересобирались.

## Проверки

- Текущая сборка выполнена на Node.js 24.22.1; npm run check прошла для 2006 HTML, 2004 canonical и 2003 BreadcrumbList.
- В каждом из 2004 содержательных HTML найден ровно один новый контакт ВК и Telegram внутри футера; технические 200/404 не имеют общего футера.
- В локальном браузере проверены ширины 320 и 1280 px. Контакты не выходят за границы; кнопка «Наверх» не перекрывает текст. Ссылки имеют правильные адреса и подчёркивание. Внешние профили не открывались, сообщения не отправлялись.
- Предпросмотр запущен в постоянном терминале и проверен открытием главной в браузере.

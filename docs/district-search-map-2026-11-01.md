## Интерфейс

В поле района можно ввести часть названия. Регистр и ё/е нормализуются; список сужается по мере ввода. Выбор подтверждается нажатием на вариант либо Enter, стрелки клавиатуры перемещают выделение. Escape, уход из поля и нажатие вне списка возвращают прежний выбранный район, не меняя фильтр. Один ввод текста не меняет URL или результаты. Сохранены Back/Forward, сброс, подгрузка и ссылки с фильтрами. При недоступном модуле поиска остаётся обычный native select.

Последнее решение пользователя заменило прежний вариант двух полей в одной строке: от 1000 px вся вертикальная группа фильтров находится **слева от карты**. На меньшей ширине фильтры стоят над картой. Все три поля используют один SVG стрелки 20×20 с одинаковым отступом, включая отключённую подгруппу.

## Карта

Яндекс Карты сохранены. На карте каталога есть переключаемый слой 18 административных районов, каждому закреплён свой насыщенный цвет. Последнее решение пользователя заменило ослабление при приближении: непрозрачность заливки постоянна, 0,36 у обычного района и 0,46 у выбранного. Толщина линий также постоянна, 3 и 4,5 px. Выбранный район имеет обводку собственного цвета с полной непрозрачностью; синяя обводка убрана. Выбор района больше не скрывает остальные плашки. При выбранном районе все 18 подписей доступны на любом масштабе; без выбора они показываются начиная с масштаба 9. Положение подписей привязано к геометрии, поэтому находящиеся за пределами видимой области названия естественно остаются вне кадра.

Слой не перехватывает указатель и не меняет область карты: масштаб подбирается по меткам клубов отдельно от полигонов. Отключение границ не удаляет клубы. Кластеризация по-прежнему разрешена только для пары «Камчатка»/«Отвага»; языковые метки и прежние общие подсказки для точно совпадающих координат сохранены. На других картах сайта новый слой не включался.

При ошибке загрузки границ карта с клубами продолжает работать, переключатель отключается и появляется короткий статус. При недоступной карте адреса остаются в карточках. Новые ключи, геокодирование каждого посетителя и платные запросы не добавлялись.

## Геоданные и происхождение

Контуры взяты из OpenStreetMap: административный уровень 5, все 18 отношений сопоставлены с [реестром районов OSM](https://wiki.openstreetmap.org/wiki/RU:Санкт-Петербург/Районы). Копия получена через Overpass 01.11.2026; отметка исходной базы `2026-10-31T22:33:20Z`. [Ссылки на каждое отношение и контрольные суммы](../outputs/S-99/boundary-source.json). Это навигационный слой из открытых геоданных, он не объявляется официальным кадастровым документом.

Генератор `scripts/build-district-boundaries.mjs` собирает замкнутые контуры, сохраняет острова и внутренние кольца, упрощает общие линии с отклонением около двух метров, не разрывая общие концы. Публичный GeoJSON использует порядок долгота/широта; при выводе в [Yandex Polygon](https://yandex.ru/dev/jsapi-v2-1/doc/ru/v2-1/ref/reference/Polygon) координаты меняются на широта/долгота. Сам GeoJSON сохраняется в `assets/district-boundaries.geojson`; запрос к Overpass при обычном просмотре сайта не нужен.

Атрибуция OpenStreetMap остаётся в общем футере под подписью «Геоданные», ссылка ведёт на [условия источника](https://www.openstreetmap.org/copyright). Прежняя удалённая строка под картой не возвращается. Координаты и принадлежность клубов автоматически по полигонам не исправлялись.

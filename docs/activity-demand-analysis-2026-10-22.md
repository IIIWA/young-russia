# Какие направления готовить для гида

Дата: 22.10.2026. Рабочий анализ петербургского каталога. Новые статьи и раздел «Популярные» не добавлены.

## Что собрано

Исходные 1533 записи занятий в 334 клубах содержат 552 разных названия. Редакционное объединение очевидных дублей, названий студий и раскрытие составных программ дали 335 тем для исследования. Ещё девять названий требуют уточнения профиля. [Полный список с запросами, счётчиками и периодами](activity-types-research-2026-10-22.md).

335 тем не означают 335 будущих статей. В списке есть конкретные занятия, подвиды, общие направления, пространства и форматы встреч. Например, «Танцы», «Современные танцы» и «Хип-хоп» пересекаются; «Коворкинг» описывает пространство. Такие записи нужны для полноты исследования, а окончательная структура статей должна учитывать их пересечение.

Первичная проверка завершена для всех 335 тем: 335 разных запросов, 5415 сохранённых строк результатов. У 81 пробного запроса счётчик равен нулю. Девять широких запросов достигли ограничения первой страницы в 200 строк: их детализация не полная. Фильтры и целостность записей проверены программно, [свидетельства](../outputs/activity-research-check-2026-10-22.json). Это полное покрытие рабочего списка одним пробным запросом, а не исчерпывающее исследование всех формулировок спроса.

Число клубов отражает исходные записи каталога, а не проверенный сегодня набор. Клуб учитывается один раз в каждой теме; он может встречаться в нескольких темах. У составной программы не подтверждаются отдельные группы автоматически. Происхождение каждого объединения и исходные подписи сохранены в [реестре](../data/research/activity-types-2026-10-22.json), правила в [конфигурации](../data/research/activity-type-normalization-2026-10-22.json).

## Как интерпретировать Wordstat

Для каждой темы подготовлен один пробный запрос. Для большинства занятий добавлено «бесплатно»; у добровольчества и общественных программ измеряется общий интерес. Эти режимы нельзя сравнивать как единый рейтинг. Регион: Санкт-Петербург, все устройства. Это не исследование спроса всей России.

Сервис показывает два разных периода: 08.09.2026 - 07.10.2026 и 21.09.2026 - 21.10.2026. Они сохранены отдельно для каждой темы. Есть предупреждение о частичной недоступности данных. Нулевой ответ одного запроса не доказывает отсутствие спроса; для редких занятий потребуется проверка синонимов и общих названий.

Общий счётчик и строки таблицы Wordstat различаются. Их нельзя подменять друг другом, складывать пересекающиеся запросы или считать числом уникальных посетителей. В таблице ниже приведены именно отдельные строки из результатов за первый из указанных периодов. [Исходные наблюдения](../data/research/wordstat-2026-10-22/activity-demand.json).

## Почему большой счётчик не определяет выбор статьи

- «Шахматы бесплатно» содержит онлайн-игры; «волейбол бесплатно» и «баскетбол бесплатно» содержат трансляции и аниме.
- «Фитнес бесплатно» содержит первое посещение платных клубов, музыку и тренировочные программы.
- «Английский язык бесплатно» включает самостоятельное обучение, приложения и материалы.
- «Социальные проекты» и «волонтёрство» измерены без слова «бесплатно» и относятся к другому намерению поиска. Их числа не сравниваются с бесплатными секциями.
- Один клуб с редким занятием может заслуживать полезной страницы, даже если пробный запрос не показал спроса.

## Что уточнить в каталоге

Неясные названия: «Стиль», «Студия “Стиль”», «Горизонт», «Ар-деко», «Ударная», «Юный каскадёр», «Клей, рисуй», студия оригинального жанра Way Out и «Индивидуальные консультации». Не выводить профиль только из имени студии.

«Переплётное дело» не классифицировано действующими правилами пяти направлений. Предлагаемая будущая подгруппа: «Ремёсла». Общая таксономия сайта в этой работе не менялась.

## Как позже устроить «Популярные»

Сохранить пять основных направлений. «Популярные» сделать отдельной подборкой ссылок на уже подготовленные статьи из разных направлений. Одна статья сохраняет один адрес; её показ в подборке не создаёт копию страницы. Состав подборки согласовать после подробной проверки кандидатов, а затем уточнять по поисковым показам и реальным переходам сайта.

Добавлять статьи небольшими партиями: уточнение запросов и аудит клубов, содержательный прототип, согласование, внедрение в Nuxt и только затем публикация. До согласования не создавать сотни однотипных страниц из этого реестра.

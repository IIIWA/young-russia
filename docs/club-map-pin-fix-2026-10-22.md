# Отметки клубов во встроенных картах

Дата: 22.10.2026. Задача S-62 по замечанию пользователя к [странице «Мы-вместе!» клуба «Патриот»](https://young-russia.ru/activities/vyborgsky-patriot-molodyozhnoe-obedinenie-my-vmeste-04.html).

## Причина

В основном каталоге координаты «Патриота» были: широта `60.109951`, долгота `30.258333`. Общий шаблон `clubLocationMarkup()` для пользовательских координат встраивал карту через короткую ссылку `api-maps.yandex.ru/frame/v1/-/...`, не передавая явную отметку. Короткая ссылка «Патриота» перенаправляла на сохранённый вид карты с адресом подъезда, но без маркера.

Это воспроизведено в настоящем виджете Яндекса: у старой карты отсутствовали элементы отметки, у карты с явно переданным `pt` появился видимый значок размером 26×44 px. Проверка S-60 сверяла данные районных карт и не проверяла видимый значок внутри отдельного iframe. Это разные проверки; замечание пользователя выявило пробел в проверке встраиваний.

## Исправление

Общий шаблон теперь формирует каждую встроенную карту по координатам из реестра: центр, уличный масштаб и отметка заданы явно. Ссылка «Открыть в Яндекс Картах» также передаёт точку. Исходные пользовательские ссылки и происхождение координат сохранены в реестре.

Исправление действует на карточках клубов и страницах всех направлений. Для «Юности» Центрального района сохранены обе карты с разными координатами. Там, где координат нет, выводятся пояснение «Точка на карте уточняется» и поиск адреса в Яндекс Картах.

Координаты не менялись; это исправление отображения. Оставшиеся 26 вопросов по адресам, корпусам и входам не закрывались.

## Проверка всего каталога

- Проверены 334 карточки клубов. У 331 есть координаты; для них формируются 332 карты с учётом двух точек «Юности».
- Всего проверены 1868 страниц клубов и занятий, содержащих карту или пояснение об отсутствии точки.
- На этих страницах 1858 встраиваний. До исправления 1769 использовали короткую ссылку без явно заданной отметки; это не означает, что все 1769 всегда отображались без маркера, поскольку содержимое сохранённых ссылок разное.
- После исправления у всех 1858 встраиваний есть явные центр, масштаб и метка; координаты каждой метки входят в исходный набор.
- Без точки остаются «Патриот» Колпинского района, «Заречье» и «Пулковец» Пушкинского района. На их страницах нет пустой обзорной карты вместо отметки.
- Сборка и `npm run check` прошли: 1891 HTML, 1889 canonical, 1888 BreadcrumbList, sitemap 1889 URL.

В Chrome проверены настоящие виджеты на восьми страницах: занятие и карточка «Патриота», «Морской», «Маяк-Олимпикс», «Феникс», «В16», Молодёжный центр Невского района и «Юность» Центрального района. Подтверждена видимость девяти значков, включая два у «Юности», и положение значков внутри рамки карты. Отдельно проверены три карточки без координат.

Видимые значки проверяются по элементу `.map-circle-placemark`: внешний контейнер `.map-placemark` у Яндекса имеет нулевой размер даже при видимом значке, поэтому его собственная геометрия не является признаком отсутствия отметки.

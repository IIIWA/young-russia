Файл Яндекса загружается асинхронно по адресу `https://mc.yandex.ru/metrika/tag.js?id=113739844`.

Блок `noscript` с изображением `https://mc.yandex.ru/watch/113739844` находится сразу после открытия `body`, перед корнем Nuxt. HTML изображения не помещён в `head`.

## Размещение кода

Яндекс рекомендует подключать счётчик на всех страницах близко к началу `head` или `body`, чтобы полнее учитывать короткие визиты. `noscript` с изображением следует размещать в `body`. [Инструкция Яндекса](https://yandex.ru/support/metrica/ru/general/creating-counter.html).

Для браузерной проверки использован рекомендованный параметр `_ym_debug=2`; сообщение `PageView` показывает регистрацию просмотра. [Проверка счётчика](https://yandex.ru/support/metrica/ru/general/check-counter.html).

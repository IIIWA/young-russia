# Импорт координат из заметки, 22.10.2026

Источник: [снимок заполненной заметки](../YoungRussiaOBS/%D0%90%D1%80%D1%85%D0%B8%D0%B2/%D0%9A%D0%BE%D0%BE%D1%80%D0%B4%D0%B8%D0%BD%D0%B0%D1%82%D1%8B/%D0%9A%D0%BE%D0%BE%D1%80%D0%B4%D0%B8%D0%BD%D0%B0%D1%82%D1%8B%20%D0%BA%D0%BB%D1%83%D0%B1%D0%BE%D0%B2%20%E2%80%94%20%D0%B2%D0%B2%D0%BE%D0%B4%202026-10-22.md). Снимок сохранён перед пересборкой списка, потому что клубы с новыми точками исчезают из очереди проверки.

- В снимке 296 карточек: 76 пустых, 13 с пометкой об отсутствии точных координат и 207 с координатами. Из 207 одна точка «Маяка-Олимпикса» уже была в реестре; добавлено 206 новых.
- Для каждой новой точки сопоставлены район, название клуба и адрес из каталога; сохранены широта, долгота и ссылка на Яндекс Карты в `data/manual-club-coordinates.json`.
- Пока шёл импорт, пользователь дополнил рабочую заметку. По четырём снимкам дополнений внесены ещё 19 точек: 12 из первой партии, 3 из второй, 1 из третьей и 3 из четвёртой. Затем добавлена ещё 1 точка «Радуги» Пушкинского района. Итого из пользовательской заметки за задачу добавлено **226 точек**. Рабочую заметку пользователь продолжает заполнять; это срез на момент релиза 22.10.2026.
- У «Параллели» в ссылке источника пропущена первая буква `h`; в реестре ссылка записана с исправленным `https://`.
- У «Молодёжного центра» в заметке две организации по ул. Бабушкина, 42. Для каталожного адреса 42, корп. 4А взята первая точка с подписью «корп. 4»; точка у корп. 1 не использована. Запись помечена приблизительной до сверки корпуса.

Для прототипов noindex следует оставить доступным для чтения роботом. Добавление `Disallow: /prototype/` скроет от него noindex и само по себе не обеспечит удаления URL из поиска: [Google: блокирование индексации](https://developers.google.com/search/docs/crawling-indexing/block-indexing).

Согласованные canonical и sitemap достаточны для текущей схемы alias; дополнительный 301 directory → index возможен позже. Canonical остаётся сигналом предпочтения, поисковик выбирает итоговую версию самостоятельно: [Google: canonicalization](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls).

## Улучшения, которые не блокируют выпуск

1. **675 title длиннее 85 символов.** Названия несут занятие, клуб, район и город; уникальность сохранена. Порог 85 является эвристикой аудита, не нормативным пределом поисковика. Массовое механическое усечение сейчас может уничтожить различимость клубов. Можно позже сокращать повторяющийся бренд/географический суффикс и проверять CTR по страницам. Google указывает, что фиксированного предела длины title нет, но выдача обрезает его под ширину устройства: [официальная документация title](https://developers.google.com/search/docs/appearance/title-link).
2. **Пять orphan activity-страниц «Ракеты».** Все относятся к временно закрытому клубу, содержат заметное предупреждение о ремонте и неизвестной дате открытия; одна независимо проверена в live. Сохранение 200/self-canonical/sitemap позволяет старым посетителям увидеть полезное предупреждение. Отсутствие входящих ссылок не предлагает занятия как действующие. Для текущего временного статуса это допустимое решение; при окончательном закрытии пересмотреть судьбу страниц, не перенаправлять автоматически на нерелевантный клуб. Постоянное закрытие источником не подтверждено.
3. **OG/Twitter.** В проверенном dist метатеги отсутствуют у 2628/2628 страниц. Это недостаток предпросмотра при отправке ссылки, не блокировка поисковой индексации. В source `CatalogPage.vue`, `page-seo.mjs`, `check-seo.mjs` управляющий уже добавил OG/Twitter; проверены корректность общей схемы URL и наличие выбранных изображений. Готовый HTML с изменением ещё не проверен: требуется итоговая общая сборка и её check. Общая fallback-иллюстрация используется для 2608 страниц, районные hero для 18 и собственные hero для двух статей. Тематические картинки каждой activity не обязательны для этого выпуска.
4. **Вес каталогов.** Готовый локальный HTML `/directions/index.html` ~1,69 МБ, главной ~0,79 МБ без сжатия; это повод для отдельной оценки загрузки, JS/hydration и мобильного UX. Сам вес не доказывает плохие Core Web Vitals. Доказательств зелёного PageSpeed нет: [ответ API](../../outputs/S-96/pagespeed-before.json) — HTTP 429/quota. Оценка не получена.
